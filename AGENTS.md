* Update [`CHANGELOG.md`](CHANGELOG.md) when making changes to any of the components within this repository. Follow the format and examples provided by the [Keep a Changelog](https://keepachangelog.com/) project. Do not add entries for changes made to files relating to the docs, local development environment, continuous integration pipeline, or deployment code. If you don't know what release you are contributing to, ask the user instead of picking or inventing one. For changelog entries that describe software updates, include both the new and previous version using semantic versioning (e.g., 0.1.0) when possible. 
* Use the documentation in this repository to understand how this code is intended to be used and developed.
